Capital One : les contrôles qui auraient pu limiter la fuite

Le magazine Security Magazine recense en août 2019 les mesures de sécurité qui auraient pu éviter ou réduire l'exposition des données de Capital One.

Par Nathan Belkacem2019Sources : Security Magazine

Un mois après l'annonce du piratage de Capital One, Security Magazine rassemble l'avis de professionnels de la sécurité sur les contrôles qui auraient pu faire la différence.

Parmi les pistes évoquées : limiter les droits accordés aux services hébergés dans le cloud au strict nécessaire, surveiller les accès inhabituels aux espaces de stockage, et chiffrer les données sensibles de façon à ce qu'un identifiant volé ne suffise pas à les lire.

L'article rappelle que la sécurité dans le cloud est une responsabilité partagée : le fournisseur protège l'infrastructure, mais la configuration des services relève de l'entreprise cliente.
